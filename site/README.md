# AD VERBUM — сайт бюро переводов

Действующий сайт adverbum.ru, пересобранный в самостоятельный статический код.
Ни Tilda, ни tb.ru, ни внешних CDN — всё лежит рядом с сайтом и работает само.

## Как загрузить на хостинг

1. Распакуйте архив.
2. Загрузите **содержимое** папки в `public_html` вашего хостинга — так, чтобы
   `index.html` оказался в корне, рядом с ним папки `css`, `js`, `assets`.
3. Старые файлы можно удалить: папки `index_files` и `from_files` больше не нужны.
   Файл `from.html` в архиве есть — он перенаправляет на новую страницу контактов,
   чтобы не сломались ссылки и закладки на старый адрес. Его удалять не надо.
4. Откройте сайт и проверьте. Если браузер показывает старую версию — обновите
   страницу с очисткой кэша (Ctrl+F5, на Mac Cmd+Shift+R).

Сборка не нужна, PHP и база данных не нужны — это обычная статика.

## Структура

```
index.html        главная страница
contacts.html     страница «Связаться с нами» (была from.html)
privacy.html      политика конфиденциальности
from.html         перенаправление со старого адреса
css/style.css     все стили
js/main.js        появление блоков и кнопка «наверх»
assets/           логотип, обложка, иконки, шрифты
```

## Что исправлено по сравнению со старой версией

- **Телефон в шапке вёл на `tel:+1 123 456 78 90`** — заглушку из шаблона Tilda.
  Нажатие на номер звонило в никуда. Теперь везде `tel:+79777822555`.
- `<link rel="canonical">` указывал на `best.houses.msk.tilda.ws` — поисковикам
  сообщалось, что настоящая страница на поддомене Tilda, а не на adverbum.ru.
- Заголовок страницы был «adverb», описание — «adverbumtranslateagency».
- Страница заявки лежала на другой платформе (tb.ru) и называлась `from.html`
  вместо `form.html`. Теперь это `contacts.html` в составе сайта.
- **Все изображения грузились с серверов Tilda.** Если бы проект в Tilda удалили,
  сайт остался бы без картинок. Теперь всё хранится у вас.
- Убраны 24 обращения к tildacdn, 5 к selcdn и загрузка шрифтов с Google.
- Вёрстка адаптирована под телефоны и планшеты.
- Добавлена микроразметка ProfessionalService и Open Graph для мессенджеров.
- Опечатка «оффициальный» в блоке цен.

Яндекс.Метрика (счётчик 97814893) сохранена на обеих страницах.

## Перед публикацией: реквизиты в политике

В `privacy.html` три поля помечены жёлтым прямо на странице — полное
наименование (ИП или ООО), ИНН и ОГРН. Их нужно подставить, иначе документ
формально не действует. Найти легко: откройте страницу, жёлтое видно сразу.

Текст написан под реальное положение дел на сайте: форм нет, данные собирает
только Яндекс Метрика, обращения приходят по телефону и в мессенджеры.
Перед публикацией его стоит показать юристу — это шаблон, а не юридическая
консультация.
