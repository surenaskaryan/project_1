# AD VERBUM — сайт бюро переводов

Переработанная версия сайта adverbum.ru: статический сайт без сборки и зависимостей.
Логотип взят с исходного сайта и оставлен без изменений.

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

Деплой — загрузить файлы на любой хостинг (GitHub Pages, обычный shared-хостинг, Timeweb, Beget).
Сборка не нужна.

## Структура

```
index.html        вся разметка страницы
css/style.css     дизайн-система и анимации
js/main.js        интерактив (формы, фильтры, анимации)
assets/           логотип, иконки, шрифты
```

## Что нужно заполнить перед публикацией

| Что | Где | Сейчас |
|---|---|---|
| Приём заявок | `js/main.js` → `CONFIG.formEndpoint` | пусто → заявка уходит в WhatsApp |
| Режим работы | `index.html`, блок «Контакты» (помечен `ЗАПОЛНИТЬ`) | «Уточните по телефону» |
| Telegram | ссылки `t.me/+79777822555` | номер вместо @username |
| Политика конфиденциальности | модальное окно `#policy` (помечено `ЗАПОЛНИТЬ`) | типовой текст, нужна проверка юристом |
| Цены | отдельного блока цен нет | вместо цен — бесплатный расчёт за 15 минут |

### Приём заявок

Пока `CONFIG.formEndpoint` пустой, форма открывает WhatsApp с готовым текстом заявки —
работает сразу, без бэкенда. Когда появится обработчик (PHP-скрипт, CRM, Telegram-бот),
укажите его URL:

```js
var CONFIG = {
  formEndpoint: 'https://adverbum.ru/send.php'
};
```

Форма отправит туда `POST` с полями `service`, `name`, `phone`, `comment`, `file`.
Если запрос не пройдёт, сработает тот же WhatsApp-фолбэк — заявка не потеряется.

### Аналитика

Цель `lead_submit` отправляется автоматически, если на странице подключены
Яндекс.Метрика (задайте `window.YM_ID`) или Google Analytics.

## Что изменено по сравнению с прототипом

**Конверсия**
- форма расчёта на первом экране вместо одной кнопки внизу страницы;
- телефон и кнопка расчёта закреплены в шапке, на мобильных — нижняя панель «Позвонить / WhatsApp / Заявка»;
- плавающие кнопки мессенджеров;
- заголовок с конкретикой («нотариальный перевод за 1 день») вместо названия компании;
- блоки доверия: сроки, этапы работы, документы, FAQ, способы получения и оплаты;
- каждая услуга ведёт в форму с уже выбранной услугой.

**Содержание**
- услуги, языки, условия оплаты и доставки перенесены с исходного сайта;
- добавлены разделы: этапы работы, список документов, FAQ, расширенный список языков с поиском;
- микроразметка `ProfessionalService` для поисковиков, Open Graph для мессенджеров.

**Анимации**
- появление блоков при прокрутке, счётчики, смена слов в заголовке;
- анимированный фон первого экрана, бегущая строка языков;
- прогресс-линия этапов работы, наклон карточек за курсором, магнитные кнопки;
- анимации формы: маска телефона, подсветка ошибок, загрузка, галочка успеха;
- все анимации отключаются при системной настройке «уменьшить движение».
